Week 4, day 3. Organization assignments. [[slnc 1200]] Today's objective is Organization Assignments, in the Organizations domain. [[slnc 600]] In one line: Configure values that default and values that users are allowed to select. [[slnc 1200]] Let's start with the mental model. [[slnc 500]] Default assignments propose an initial organization value during staffing. Allowed assignments constrain valid selections. A default should normally also be allowed. Worker assignments can populate worktags on downstream transactions. A subordinate organization inherits the Default and Allowed organizations of its superior unless it has its own values; the Inherited from Superior check box on the Organization Assignments tab shows this, and entering a value overrides the inherited one. [[slnc 1200]] Now, the distinctions you need to know. [[slnc 500]] Default: Proposed starting value. [[slnc 700]] Allowed: Valid selection set. [[slnc 700]]  [[slnc 600]] Here's how it shows up at work. [[slnc 500]] Default Cost Center 4100 but permit two approved alternatives in the allowed set. [[slnc 1200]] Task and report names to recognize: Assign Organizations, Maintain Organization Assignments, Hire, and Change Job. [[slnc 1200]] And the exam trap to watch for. [[slnc 500]] A default value is not necessarily the only permitted value. Check defaults, allowed values, and inheritance together. [[slnc 1500]] Quick check.
