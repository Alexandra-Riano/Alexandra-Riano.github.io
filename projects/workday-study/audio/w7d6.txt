Week 7, day 6. Advanced security group types. [[slnc 1200]] Today's objective is Advanced Security Group Types, in the Security domain. [[slnc 600]] In one line: Pick the right job, membership, combination, rule-based, or non-worker group. [[slnc 1200]] Let's start with the mental model. [[slnc 500]] Some groups derive members from worker data. Job-based groups use one job criterion, such as job profile, job family, or management level, and can be constrained to the member's own organizations or unconstrained. Location membership groups include workers at chosen locations and are always unconstrained. Organization membership groups include members of chosen organizations, including hierarchies, and can be constrained or unconstrained. Combination groups reuse other groups. Aggregation: members of any included group, each keeping its own constraints. Intersection: members of all included groups, with constraints intersected; it cannot include intersection, rule-based, or integration system groups. Segment-based: controls access to segments of values, such as document categories. Rule-based groups filter a baseline group with a security rule; changing the rule needs no activation. Service center and integration system groups give access to non-workers. [[slnc 1200]] Now, the distinctions you need to know. [[slnc 500]] Aggregation: Any included group (union). [[slnc 700]] Intersection: All included groups, constraints intersected. [[slnc 700]] Rule-based: Baseline group filtered by a security rule. [[slnc 700]] Integration system: Access for integration system users (I S Us). [[slnc 700]]  [[slnc 600]] Here's how it shows up at work. [[slnc 500]] Only employees in Australia should update their own legal name. Create a rule-based group with Employee As Self as the baseline and a rule on country, then use it in the self-service policy. [[slnc 1200]] Task and report names to recognize: Create Security Group, Create Security Rule, Test Security Rule, View Security Groups for User, and Maintain Fields for Security Rules. [[slnc 1200]] And the exam trap to watch for. [[slnc 500]] Location membership groups are always unconstrained.
