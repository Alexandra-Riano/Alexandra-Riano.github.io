Week 7, day 4. Security groups. [[slnc 1200]] Today's objective is Security Group Types, in the Security domain. [[slnc 600]] In one line: Choose the right membership method and constraint context. [[slnc 1200]] Let's start with the mental model. [[slnc 500]] Workday-delivered groups have Workday-maintained criteria. Role-based groups derive membership from assignable roles and can be constrained or unconstrained. User-based groups use explicitly maintained membership. Constraints determine the target population. [[slnc 1200]] Now, the distinctions you need to know. [[slnc 500]] Role-based constrained: Role membership plus supported context. [[slnc 700]] User-based: Named maintained membership. [[slnc 700]] Workday-delivered: Workday-owned criteria. [[slnc 700]]  [[slnc 600]] Here's how it shows up at work. [[slnc 500]] Use role-based constrained security for regional HR partners who should see only workers in organizations they support. [[slnc 1200]] Task and report names to recognize: Create Security Group, Edit Security Group, Assign Roles, and Maintain Users in User-Based Security Group.
