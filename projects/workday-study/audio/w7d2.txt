Week 7, day 2. Custom reports. [[slnc 1200]] Today's objective is Create Custom Reports, in the Reporting domain. [[slnc 600]] In one line: Choose a data source and objects before configuring fields, filters, prompts, sorting, and sharing. [[slnc 1200]] Let's start with the mental model. [[slnc 500]] The data source is the most important choice: it sets the population and the primary business object, and it is the biggest factor in report performance. Choose the smallest data source that has all the data, and prefer indexed data sources. The primary object decides which related objects you can reach; both decide the available fields. Advanced reports reach related objects one level deep; deeper data needs a calculated field. Advanced report tabs: Columns (fields), Sort, Filter (primary object), Subfilter (related objects; runs before the filter), Prompts (defaults and hiding), Output (table, chart, worklet), Share, and Advanced (web service, temporary report date, Optimized for Performance). Reports are not shared by default; you can share only with users who can access the data source and its filter. Test returns the first 10 rows; Run returns all. [[slnc 1200]] Now, the distinctions you need to know. [[slnc 500]] Data source: Defines population. [[slnc 700]] Primary object: Anchors related objects. [[slnc 700]] Filter versus subfilter: Primary object versus related objects (subfilter runs first). [[slnc 700]] Share: Only to users with access to the data source and filter. [[slnc 700]]  [[slnc 600]] Here's how it shows up at work. [[slnc 500]] For worker, manager, and cost-center data, choose a source whose primary object exposes those relationships. [[slnc 1200]] Task and report names to recognize: Create Custom Report, Copy Standard Report to Custom Report, Business Object Details, Schedule a Report, Scheduled Future Processes, and Create Custom Report from Here. [[slnc 1200]] And the exam trap to watch for. [[slnc 500]] Do not begin with columns. Confirm the population and object relationships first. [[slnc 1500]] Quick check.
