Today's objective is Organization Assignments, in the Organizations domain. [[slnc 600]] In one line: Configure values that default and values that users are allowed to select. [[slnc 1200]] Let's start with the mental model. [[slnc 500]] Default assignments propose an initial organization value during staffing. Allowed assignments constrain valid selections. A default should normally also be allowed. Allowed values also drive what can be chosen in the Default prompt, and workers hired or transferred into the organization automatically join its default organizations. A subordinate organization inherits the Default and Allowed organizations of its superior unless it has its own values; the Inherited from Superior check box on the Organization Assignments tab shows this, and entering a value overrides the inherited one. [[slnc 1200]] Now, the distinctions you need to know. [[slnc 500]] Default: Proposed starting value. [[slnc 700]] Allowed: Valid selection set.
