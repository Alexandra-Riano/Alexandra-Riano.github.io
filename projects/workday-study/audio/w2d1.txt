Week 2, day 1. Job Management. [[slnc 1200]] Today's objective is Job Management Options, in the Staffing Setup domain. [[slnc 600]] In one line: Use organization-level restrictions for flexible, high-volume staffing. [[slnc 1200]] Let's start with the mental model. [[slnc 500]] Job Management emphasizes speed and flexibility. No open position is required to hire. Restrictions apply across the supervisory organization, there is no system-imposed limit on jobs, and the job ends when the worker leaves. Reporting covers current headcount only, so control relies on hire, contract, and transfer workflows. Subordinate organizations created under a parent inherit its staffing model, but each can be changed, so one hierarchy can mix models. Changing a parent does not change existing subordinates; use Edit Staffing Model on each. [[slnc 1200]] Now, the distinctions you need to know. [[slnc 500]] Best fit: Flexible or high-volume staffing. [[slnc 700]] Restriction level: Supervisory organization. [[slnc 700]] Changing the model: Edit Staffing Model, only before positions or restrictions exist. [[slnc 700]]  [[slnc 600]] Here's how it shows up at work. [[slnc 500]] A support center hires many agents under shared job, location, worker-type, subtype, and time-type restrictions. [[slnc 1200]] Task and report names to recognize: Edit Staffing Model, Maintain Staffing Models, and Set Hiring Restrictions. [[slnc 1200]] And the exam trap to watch for. [[slnc 500]] Edit Staffing Model works in either direction only until positions exist (Position Management) or hiring restrictions are set (Job Management). After that the task is no longer available. Before changing, rescind in-progress hiring or position restriction events, Move Worker (By Organization) events, and staffing events.
